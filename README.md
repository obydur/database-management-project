# Database Management – University Project

**Academic Project | SQL | RDBMS | NoSQL | JSON**

## Project Overview

This repository contains my university project on Database Management Systems. It focuses on relational database concepts, SQL, SQL DOM, NoSQL technologies, JSON data management, and database security.

The project explores database management concepts and the relationship between relational and semi-structured data.

- Relational Database Management Systems (RDBMS)
- SQL and Database Queries
- SQL DOM
- NoSQL Database Concepts
- JSON Data Management
- SQL Injection and Database Security
